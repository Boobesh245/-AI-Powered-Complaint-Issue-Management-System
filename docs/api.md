# REST API Reference Specification

Base URL: `http://localhost:8000/api`
Interactive Swagger Docs: `http://localhost:8000/docs`

## 1. Authentication Endpoints
- `POST /api/auth/register` — Register a new student/user or staff account.
- `POST /api/auth/login` — Login with credentials and receive JWT bearer token.
- `GET /api/auth/me` — Retrieve active user session profile.
- `POST /api/auth/logout` — Revoke and log out.
- `POST /api/auth/forgot-password` — Password reset recovery request.
- `POST /api/auth/reset-password` — Update password with token.

## 2. Complaint Management Endpoints
- `GET /api/complaints` — Filter, search, paginate, and sort complaints.
- `POST /api/complaints` — Submit a new complaint (triggers AI triage and duplicate check).
- `GET /api/complaints/{id}` — Retrieve complete complaint details, comments, and activity timeline.
- `PUT /api/complaints/{id}` — Edit complaint metadata.
- `PATCH /api/complaints/{id}/status` — Update ticket status (`in_progress`, `resolved`, `closed`, `reopened`).
- `PATCH /api/complaints/{id}/priority` — Adjust priority (`critical`, `high`, `medium`, `low`).
- `PATCH /api/complaints/{id}/assign` — Allocate department staff specialist.
- `POST /api/complaints/{id}/comments` — Add discussion comment with attachments.
- `POST /api/complaints/bulk/assign` — Bulk staff assignment.
- `POST /api/complaints/bulk/status` — Bulk status update.
- `POST /api/complaints/upload` — Upload file attachment.

## 3. Analytics Endpoints (MongoDB Aggregations)
- `GET /api/analytics/overview` — KPI metrics: Total, Pending, In Progress, Resolved, SLA compliance, Avg Resolution Hours.
- `GET /api/analytics/complaint-trends` — Daily complaint intake vs resolution series.
- `GET /api/analytics/status-distribution` — Status doughnut dataset.
- `GET /api/analytics/priority-distribution` — Severity bar dataset.
- `GET /api/analytics/category-distribution` — Top complaint categories.
- `GET /api/analytics/department-performance` — Departmental resolution rates.
- `GET /api/analytics/resolution-time` — Average, median, min, max resolution statistics.
- `GET /api/analytics/sla` — SLA compliance, at-risk, and breached counts.
- `GET /api/analytics/staff-performance` — Staff efficiency leaderboard.
- `GET /api/analytics/satisfaction` — Ratings distribution and satisfaction trends.
- `GET /api/analytics/ai-insights` — Automated trend warnings and duplicate list.

## 4. Reports & Exports Endpoints
- `GET /api/reports/complaints/csv` — Stream formatted CSV report.
- `GET /api/reports/complaints/pdf` — Stream official PDF report generated by ReportLab.
- `GET /api/reports/summary` — Aggregated executive report summary.
